### 문제 이해
- 야근을 하면 야근 피로도가 쌓임
- 야근 피로도: 야근을 시작한 시점에서 남은 일의 작업량을 제곱해서 더한 값
- Demi는 N시간 동안 야근 피로도를 최소화해 일할 것임
- Demi가 1시간 동안 작업량 1만큼을 처리할 수 있음
- 퇴근까지 남은 N 시간과 각 일에 대한 작업량 works에 대해 야근 피로도를 최소한 값
#### input & output
- input: works 배열, n
- output: 야근 피로도를 최소화한 값
---
### 고안 방식
- 남은 일의 작업량을 제곱해서 더하기 때문에 최대한 남은 일의 작업량을 작게 만들어야 함
- 즉, 작업량이 큰 숫자이면 안 됨 -> 큰 숫자부터 줄이기
#### 최종 방식
- PriorityQueue 이용
