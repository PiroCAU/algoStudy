### 문제 이해
- 경주로 부지는 N*N 크기의 정사각형 격자 형태이며 각 격자는 1*1 크기임
- 각 격자의 칸은 0 또는 1로 채워져 있음
  - 0: 칸이 비어 있음
  - 1: 칸이 벽으로 채워져 있음
- 경주로의 출발점은 (0,0)이며, 도착점은 (N-1, N-1)임
- 출발점에서 도착점까지 도달할 수 있게 중간에 끊기지 않도록 경주로를 건설해야 함
- 상하좌우로 인접한 두 빈 칸을 연결해 건설할 수 있으며, 벽이 있는 칸에는 경주로를 건설할 수 없음
- 인접한 두 빈 칸을 상하 또는 좌우로 연결한 경주로를 직선 도로라고 하며, 만드는 데 100원이 소요됨
- 직선 도로가 서로 직각으로 만나는 지점을 코너라고 하며, 만드는 데 500원이 소요됨
#### input & output
- input: 도면의 상태를 나타내는 2차원 배열 board
- output: 경주로를 건설하는데 필요한 최소 비용
---
### 고안 방식
- BFS
#### 최종 방식값
- 방향을 가지고 있는 BFS
