### 문제 이해
- 어떤 수열의 연속 부분 수열에 같은 길이의 펄스 수열을 각 원소끼리 곱해 연속 펄스 부분 수열을 만들려 함
- 펄스 수열이란 1 또는 -1로 시작하면서 1과 -1이 번갈아 나오는 수열
- 정수 수열이 주어질 때 연속 펄스 부분 수열의 합 중 가장 큰 것을 반환
#### input & output
- input: 정수 수열 sequence
- output: 연속 펄스 부분 수열의 합 중 가장 큰 것
---
### 고안 방식
- DP
#### 최종 방식값
- [1, -1, 1, -1, ...]과 [-1, 1, -1, 1, ...]을 곱한 배열 두 경우를 미리 계산
- 현재 위치에서의 최댓값이 음수라면, 현재 값에서 새롭게 시작하는 것이 더 유리
