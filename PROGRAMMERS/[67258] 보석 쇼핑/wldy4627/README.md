### 문제 이해
- 어피치는 진열대의 특정 범위의 보석을 모두 구매하되 "진열된 모든 종류의 보석을 적어도 1개 이상 포함하는 가장 짧은 구간을 찾아서 구매"하고 싶었음
- 모든 보석을 하나 이상 포함하는 가장 짧은 구간을 찾아서 반환
- 짧은 구간이 여러 개라면 시작 진열대 번호가 가장 작은 구간을 반환
#### input & output
- input: 진열대 번호 순서대로 보석들의 이름이 저장된 배열 genres
- output: 모든 보석을 하나 이상 포함하는 가장 짧은 구간
