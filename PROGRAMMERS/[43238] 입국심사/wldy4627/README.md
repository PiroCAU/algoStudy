### 문제 이해
- n명이 입국심사를 위해 기다리고 있고, 각 입국심사대에 있는 심사관마다 심사하는데 걸리는 시간이 다름
- 동시에 한 명만 심사할 수 있음
- 가장 앞에 서 있는 사람은 비어있는 심사대로 가서 심사받을 수 있음
- 모든 사람이 심사를 받는데 걸리는 시간을 최소로 하고 싶음
#### input & output
- input:
  - 입국심사를 기다리는 사람 수 n
  - 심사관이 한 명을 심사하는데 걸리는 시간이 담긴 배열 times
- output: 모든 사람이 심사를 받는데 걸리는 시간의 최솟값
---
### 고안 방식
- 이분탐색
#### 최종 방식값
- (1 ~ 최대 시간)을 초기 상태로 해서 이분탐색을 하며 모든 인원을 처리할 수 있는 최소 시간을 구하기
