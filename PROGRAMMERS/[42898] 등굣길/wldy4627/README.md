### 문제 이해
- 물에 잠기지 않은 지역을 통해 학교에 가고자 함
- 집에서 학교까지 가는 길은 m x n 크기의 격자모양으로 나타남
- (1, 1)은 집, (m, n)은 학교
- 오른쪽과 아래로만 움직여 집에서 학교까지 갈 수 있는 최단경로 개수를 1,000,000,007로 나눈 나머지
#### input & output
- input: m, n, 물이 담긴 지역의 자표를 담은 2차원 배열 puddles
- output: 최단경로 개수를 1,000,000,007로 나눈 나머지
