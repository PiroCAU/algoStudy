### 문제 이해
- 판매원이 칫솔을 판매하면 그 이익이 피라미드 조직을 타고 조금씩 분배되는 형태의 판매망임
- 자신을 조직에 참여시킨 추천인에 연결되어 피라미드 식의 구조를 이루고 있음
- 판매원은 칫솔의 판매에 의하여 발생하는 이익에서 10%를 계산해 자신의 조직에 참여시킨 추천인에게 배분하고 나머지는 자신이 가짐
- 모든 판매원은 자신이 칫솔 판매에서 발생한 이익 뿐만 아니라, 자신의 조직에 추천하여 가입시킨 판매원에게서 발생하는 이익의 10%까지 자신에 이익이 됨
- 자신에게 발생하는 이익 또한 마찬가지의 규칙으로 자신의 추천인에게 분배됨
- 10%를 계산할 때에는 원 단위에서 절사하며, 10%를 계산한 금액이 1원 미만인 경우에는 이득을 분배하지 않고 자신이 모두 가짐
#### input & output
- input:
  - 판매원의 이름을 담은 배열 enroll
  - 판매원을 다단계 조직에 참여시킨 다른 판매원의 이름을 담은 배열 referral
  - 판매량 집계 데이터의 판매원 이름을 나열한 배열 seller
  - 판매량 집계 데이터의 판매 수량을 나열한 배열 amount
- output: 각 판매원이 득한 이익금을 나열한 배열 (enroll에 이름이 포함된 순서대로)
